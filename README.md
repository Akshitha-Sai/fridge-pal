##FridgePal
#About the Project

FridgePal is a smart food management web application designed to help users reduce food waste and make cooking easier. It allows users to track fridge items, monitor expiry dates, discover nearby grocery stores, and explore recipes based on available ingredients — all in one place.

#Features

The application includes a digital fridge to add and manage food items, an interactive recipe book where users can add their own recipes, and a location-based feature to find nearby stores by tracking distance. FridgePal focuses on prevention rather than reminders by encouraging smarter usage of stored food.

#Tech Stack & Design

This project was built using HTML, CSS, and JavaScript with a strong focus on clean UI, smooth animations, and user-friendly interactions. The design follows a modern glassmorphism style with responsive layouts for different screen sizes.
